Models
    - Define data structures and database entities
    - Contain validation attributes
    - Represent domain objects

Controllers
    - Handles HTTP request and response 
    - Routes requests to appropriate services
    - Returns formatted responses (JSON, XML, etc.)

Services
    - Contain business logic and application rules
    - Implement service interfaces
    
    IService
        - Define service contracts and method signatures
        - Support dependency injection
        
    Services
        - Implement business operations
        - Coordinate between repositories and controllers

#Middleware
    - Checkpoint your request passes through on the way to your controller
    - Handles authentication, logging, error handling
    - Can modify request/response pipeline

#IEnumerable
    - Interface for iterating over collections
    - Provides LINQ extension methods
    - Supports deferred execution
